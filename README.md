# SQL Sales Analysis Project

This project demonstrates core database analytics using Python, Pandas, and SQLite3.

## Features & SQL Concepts Covered:
- **Basic Querying**: Filters and aggregations using SELECT, WHERE, GROUP BY, and ORDER BY.
- **Advanced Processing**: Nested subqueries to find Global Average Order Value (AOV).
- **Conditional Logic**: Categorizing value segments using CASE statements.
